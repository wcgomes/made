Wire interface: protocol major 1, <=256 KiB frames, <=64 KiB chunks, <=16 nonterminal requests and <=256 queued data chunks per tab, ten-second RPC deadlines, explicit cancellation. Envelope binds random tab capability + server authority + epoch + request id + root generation; RemotePath is lossless POSIX bytes, not host PathBuf. Closed operations and upload/terminal separation are specified in design.md. TerminalTransport supplies poll/write/resize/status/detach; explicit remote Close is distinct. RootResolver and SessionCommandSink are asynchronous authority-aware ports; local behavior stays default. Remote OpenCode snapshots reuse bridge SessionSnapshot with explicit POSIX lexical validation and no host filesystem resolution; SSH-10 Grok state/snapshot/event data uses its own additive DTOs and `LaunchTarget::Grok`, never a `SessionSnapshot` overload. These phase-1 signatures stay frozen except the authorized `TerminalOutput` payload field and additive Grok operations below. Compatible implementation-local names may differ, not guarantees.

Native-supervisor delta:
- A follows `protocol.rs`, `made-terminal/src/transport.rs`, `made-bridge/src/state.rs`, and `made-platform/src/lib.rs` only as registrar, plus the desktop input gate in `terminal_view.rs`. Do not change `PROTOCOL_MAJOR`, `WireEnvelope`, `TerminalTransport` methods, `PathSemantics`, or `SessionSnapshot`, and do not overload `SessionSnapshot` with Grok data. The authorized contract changes are the `TerminalOutput { data: Chunk, done: bool }` payload, required with no serde default, and the additive SSH-10 Grok state/snapshot/event operations plus `LaunchTarget::Grok`, both inside the closed major-1 enum. Keep `Capabilities.tmux`; producers encode false and nobody branches on it. Do not add a tmux operation or a VT-snapshot verb. Register `detach` in task 3.1. Do not edit `emulation.rs` to reach alacritty's private inactive grid.
- B follows `ssh.rs`, new `detach.rs`, and `client.rs`. Probe and stage scripts must not name, execute, or version-check tmux. Detach starts a new session, ignores SIGHUP, closes inherited stdio, and uses a private runtime directory. Unsupported remote families fail preflight; they do not fall back to tmux. When enqueueing terminal bytes, preserve `TerminalOutput.done`; do not collapse it into `PtyEvent::Data` and do not treat an empty poll as completion.
- C follows `main.rs` and `supervisor.rs` plus the listed runtime tests, and `grok.rs` for bounded Grok ingestion and the consented install. The supervisor owns `PtySession`, the loopback bridge, watchers, and a `TerminalCore` with a 10,000-line bound. After `Attached`, it emits the resnapshot on `TerminalOutput` and sets `done: true` on the last resnapshot frame before any live byte. Later live frames use `done: false`. No tmux binary, socket, config, probe, or fallback.
- E follows `tests/ssh/harness.py` and `tests/ssh/parity.py`. Prerequisites exclude tmux. Do not install tmux or Rust on the remote or in a development container. A missing companion binary is unrun, not a pass.
- D has no wire-struct delta, must not add a tmux gate, and must not mark the terminal current before `TerminalOutput` `done: true`.
