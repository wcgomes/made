# 2026-11-06 v0.1.0 Release

**Status:** `v0.1.0` published from the final `main` by `release.yml` run 42142416024 (PR #2, merge commit 8b922e9). Covers the `grok-native-hook` and `add-release-auto-update` changes; contracts are in `specs/changes/`, decisions in [ADR 0006](../decisions/0006-native-grok-hook.md) and [ADR 0007](../decisions/0007-github-releases-velopack-unsigned.md).

## What happened

- Iteration releases and tags `v0.1.0` to `v0.1.9` were cut during implementation so `upgrade-check.yml` ran between real releases. Several failed for harness or test-race reasons (`v0.1.3`, `v0.1.4` cancelled before publish; `v0.1.1`, `v0.1.5`, `v0.1.7` failed only the upgrade check), each fixed by a newer iteration. All iteration releases and tags were deleted, then `v0.1.0` was released again from the final `main`.
- Repository settings were configured afterwards: `release` environment, "main: PR only" and "release tags" rulesets ([details](../operations/release-ci.md#repository-settings)). Immutable releases are not enabled.
- `grok-made` dropped from a hand-installed 0.1.1 to 0.1.0 to equal the workspace version. A machine that installed an iteration must uninstall Made, run `grok plugin uninstall grok-made --confirm` (locally and per SSH server), and remove staged remote version directories above 0.1.0.

## Evidence

- `CI-release`: installed-layout smoke passed on Windows setup, macOS arm64/x64 `.pkg` and `.zip`, and Linux AppImage on Ubuntu 22.04 and 24.04 (hosted runners).
- `CI-upgrade`: in-place update through the real path passed on all twelve target/form/setting combinations for the later iterations.
- `CI-probe`: apply kill points, no-FUSE AppImage launch, and the observed GitHub host list.
- Real grok 1.0.70 installs the packaged Grok plugin on all four targets.

## UNVERIFIED

- Fresh-machine installs with no admin and no optional tools (hosted runners are not fresh), including Windows 10 1809.
- Fedora, and Wayland sessions (only X11 under Xvfb ran).
- Gatekeeper and SmartScreen click-through, and the repeat prompt after an update.
- About-path restart on a real installed build (the headless UI model is tested; the interactive path is not).
- Power loss during apply on Windows and cross-filesystem Linux.
- Real signed-in Grok sessions: hook events, logged pid equal to the Grok process, Windows command resolution.
