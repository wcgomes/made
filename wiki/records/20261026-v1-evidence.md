## Verified behavior

- Home-default startup opens the resolved home as a workspace; explicit path wins over `--picker`; picker starts no process before confirmation; invalid/unresolvable home falls back terminal-only with a visible error.
- Real bash launch-local cwd follow with spaces/Unicode and unchanged profile; unsupported-shell fallback is honest; deleted-in-place shell root is marked unavailable once and recovers.
- Independent workspace tabs: three live tabs with distinct PTYs/roots/bridges; closing one leaves siblings live; final close returns to picker.
- Full-left read-only preview roundtrip: hidden input blocked, hidden shell output continues, File/Terminal/Close restore the same terminal, root change clears preview.
- Explorer: full-height glass card/header, live tree with unified 24px borderless rows, selected/opened rows using only the inset `BG_SELECTED` fill plus primary text with no row or container outline, app-drawn markers aligned to the label, expanded folders marked by glyph and brighter label, first-row selection on keyboard entry without preview, animated hide/show, a fade-only splitter (neutral hover, mint drag), hover-only scrollbars, no text header actions, no routine status chrome.
- UI: floating bandless header with a mint accent, icon-only controls, workspace tabs starting at the content-left gutter, the `MADE` wordmark before the right icon group with reserved 24/18 strip-side and exact 24/18 icon-side gaps, the `+` Open folder action after the visible tabs, and Sessions/Diagnostics/Explorer on the right with Explorer rightmost. The header row spans gutter..width-gutter with no extra horizontal padding; the strip/tabs are 26/24, the card content top is 42/36, and the last icon’s 26/24 target, selected/hover fill, and focus ring all end exactly at the card right (`content.right`) with no gutter overhang; the 14px glyph is centered in that target with normal optical padding on both sides. Workspace tabs are fill-only: idle `BG_TAB_IDLE`, hover `BG_TAB_HOVER`, selected opaque `BG_TAB_SELECTED`, all without a stroke; the close glyph scales 1.0→1.15 over 0.13 s and uses the parent hover/selected fill. The picker is an inline expandable tree with a selected-row/root path chip and no row/container outline. Scrollbars remain hover-only and fading; diagnostics stay opaque.
- Native backdrop fallback logs `applied=false` with the compositor-managed reason on Linux; `MADE_NATIVE_BACKDROP=off` logs the disabled reason and keeps in-app glass.
- Security: loopback-only bridges, 256-bit tokens, cross-workspace rejection before disclosure, foreign lifecycle events ignored, path guard, no-write preview, private logs/temp, paste-marker fixed point.

## Phase 10 fill-only tabs and darker fallback (2026-10-27)

The no-native fallback clear darkens to alpha 225 (RGB 10,11,14); the native-effect clear stays 150 and the solid fallback is unchanged. Workspace tabs drop the Explorer glass and `ACCENT` outline treatment: idle uses translucent black `BG_TAB_IDLE` (84), hover uses opaque `BG_TAB_HOVER` `#151C18`, and selected uses opaque `BG_TAB_SELECTED` `#1B231F`, all with no stroke. Selected/hover tabs are opaque; close hover uses the parent hover fill (or keeps the selected fill) and the red `ERROR` glyph scale. At that phase the test suite remained green with fmt/clippy clean.

Visual validation used refreshed temporary Xvfb captures; those images are not committed or maintained.

Xvfb without a compositor cannot show alpha blending over a light root; token tests assert the 225/150 clear alphas. Native compositor alpha, pointer, focus, and hardware behavior remain pending.

## Performance

Final release software results: 10k startup 108.7–115.3 ms first tab / 8.9–14.4 ms later; `cwd_to_root` 3.29–3.74 ms; activation 2.94–4.68 ms; input-to-render 5.11–5.39 ms; preview roundtrip 7.5–10.7 ms; Explorer hide 3–6 ms; frame p95 14.86–15.80 ms under 16.667 ms; 0 hidden grid paints; bounded hidden 3-tab memory observation. These are software-rendered product metrics, not hardware or native click-to-pixel claims. See [Performance](../performance.md).
