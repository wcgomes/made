# 2026-10-26 V1 Evidence Snapshot

**Status:** Terminal-first v1 implemented and verified on Linux x64 under Xvfb/llvmpipe software rendering. **Not release-ready.** Native Linux desktops, macOS, Windows/ConPTY, real zsh/fish/PowerShell, live real-OpenCode switching, native input, native backdrop rendering, hardware-GPU pacing, packaged launch, and observed CI artifacts remain open.

## Verified behavior

- Home-default startup opens the resolved home as a workspace; explicit path wins over `--picker`; picker starts no process before confirmation; invalid/unresolvable home falls back terminal-only with a visible error.
- Real bash launch-local cwd follow with spaces/Unicode and unchanged profile; unsupported-shell fallback is honest; deleted-in-place shell root is marked unavailable once and recovers.
- Independent workspace tabs: three live tabs with distinct PTYs/roots/bridges; closing one leaves siblings live; final close returns to picker.
- Full-left read-only preview roundtrip: hidden input blocked, hidden shell output continues, File/Terminal/Close restore the same terminal, root change clears preview.
- Explorer: full-height glass card/header, live tree, animated hide/show, hover-only divider, no text header actions, no routine status chrome.
- UI: icon-only header controls, two-tone `MADE` wordmark, tabs with background + underline/no dot, picker selected row/Close X, opaque diagnostics.
- Native backdrop fallback logs `applied=false` with the compositor-managed reason on Linux; `MADE_NATIVE_BACKDROP=off` logs the disabled reason and keeps in-app glass.
- Security: loopback-only bridges, 256-bit tokens, cross-workspace rejection before disclosure, foreign lifecycle events ignored, path guard, no-write preview, private logs/temp, paste-marker fixed point.

## Performance

Final release software results: 10k startup 108.7–115.3 ms first tab / 8.9–14.4 ms later; `cwd_to_root` 3.29–3.74 ms; activation 2.94–4.68 ms; input-to-render 5.11–5.39 ms; preview roundtrip 7.5–10.7 ms; Explorer hide 3–6 ms; frame p95 14.86–15.80 ms under 16.667 ms; 0 hidden grid paints; bounded hidden 3-tab memory observation. These are software-rendered product metrics, not hardware or native click-to-pixel claims. See [Performance](../performance.md).

## Not validated

- Native Linux X11/Wayland with real WM/compositor, pointer/keyboard, IME, clipboard, resize, title/focus, native home resolution, and real OpenCode TUI interaction.
- macOS arm64/x64 native runs, HudWindow vibrancy rendering, compositor behavior.
- Windows x64 native/ConPTY, Mica, Job Object descendant cleanup, native OpenCode.
- Real zsh/fish/PowerShell cwd runs; cmd remains explicit fallback.
- Live real-OpenCode session switching, real worktree removal/indicator, native session-map focus.
- Native IME/clipboard/mouse/paste and hardware-GPU frame pacing.
- Packaged artifact launch and observed CI run IDs/artifacts.
- Cross-user bridge DoS acceptance/reserved slot; Windows log reparse-point hardening.

## Caveats

- Native macOS/Windows backdrop paths are compile-checked only.
- `accesskit` is not enabled; platform screen-reader exposure is not claimed.
- CI workflows are configured but runs/artifacts were not observed from this workspace at snapshot time.
