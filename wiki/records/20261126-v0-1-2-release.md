# 2026-11-26 v0.1.2 Release

**Status:** `v0.1.2` published 2026-11-26 by `release.yml` run 45845063077 from tag `v0.1.2` at 03f1864 (bump PR #22), on the first attempt with every job green. The `ssh-claude-code-parity` change was archived the same day; its contract is SSH-11 of [`specs/ssh-remote-workspaces.md`](../../specs/ssh-remote-workspaces.md) with AIA-05 in [`specs/agent-integration-architecture.md`](../../specs/agent-integration-architecture.md).

## What shipped

- Remote Claude Code parity in SSH workspaces (PR #21): staged plugin and hook, server-side ownership and listing, local precedence remotely. See [Claude Code SSH](../integration/claude-code.md#ssh).
- Remote OpenCode diagnostics report "not running" or "not detected on this server" instead of a degraded sentence (PR #21). See [OpenCode](../integration/opencode.md).
- macOS Finder/Dock launches adopt the login-shell `PATH` (PR #20), the field issue from [v0.1.1](20261125-v0-1-1-release.md); it was also why Claude Code `/cd` and agent-view follow did nothing in v0.1.1 builds. See [macOS GUI launch PATH](../runtime/terminal-first.md#macos-gui-launch-path).

## What happened

- PR #21's CI failed on its feature head (CI, SSH remote companions, macOS smoke) and on the next push (CI, SSH remote companions); two fix commits followed, one for a permission-denial test that ran as root in the Linux companion container and one for the companion upload dropping `.claude-plugin/` (hidden files), and every PR check was green at merge. Both lessons are in [CI platform quirks](../testing/ci-platform-quirks.md).
- The SSH Claude Code operations are gated on the supervisor's `helper_version`, which made "every release bumps the version" a hard rule; see [Release and CI](../operations/release-ci.md#bump-and-release).
